# МАСТЕР-ПРОМПТ: продающий анимированный сайт для Radial Music

Скопируй всё ниже в новый чат вместе с архивом проекта. Работай этапами и после каждого присылай архив.

---

## РОЛЬ
Ты — senior frontend-разработчик и арт-директор. Делаешь продающий, красивый, анимированный, адаптивный сайт для коммерческого Windows-приложения. Результат всегда отдаёшь архивом (.zip) и коротким отчётом: что сделано, что не проверено.

## ПРОДУКТ
**Radial Music** — Windows 10/11. Зажал боковую кнопку мыши → круговое меню поверх любых окон и игр → выбрал сектор → отпустил. Обложка трека в центре. Яндекс Музыка (клиент и Яндекс Браузер). Круг без курсора в играх (как колесо оружия). Профили по программе, таймер сна, недавние треки, темы, свои действия, перенос настроек, обучение при первом запуске. Лицензия: ключ Ed25519, офлайн-проверка, 14 дней пробного периода.
**Тарифы:** Free (до 2 профилей, без своих действий, без создания и импорта тем, без импорта настроек) и Pro по подписке (месяц / год). Цены вынести в `src/config.js`.
**Рынок:** только Россия. Продавец — самозанятый. Оплата: ЮKassa / Prodamus / Tinkoff (выбрать по условиям самозанятого), чек в «Мой налог».

## КОНЦЕПЦИЯ И ДИЗАЙН
- Тёмная премиальная тема: фон #14141a, акценты фиолетовый #7c6cff → розовый #ff6b8e (из иконки приложения). Шрифты Unbounded (заголовки) + Manrope (текст).
- Главный образ — **интерактивное круговое меню** в hero, которое повторяет настоящее приложение.
- Стиль: крупная типографика, много воздуха, стекло и мягкое свечение, без шаблонности.
- Тон текста: коротко, по делу, без воды, без громких обещаний, которые нельзя проверить.

## СТЕК
Vite + нативный JS (ES-модули), GSAP + ScrollTrigger, Lenis (плавный скролл). По желанию: Three.js или WebGL-фон, Splitting/SplitType, Lottie. Никаких тяжёлых фреймворков. Хостинг статикой (GitHub Pages / Netlify). Серверная часть — только для оплаты и выдачи ключей.

## АНИМАЦИИ (обязательно)
Заголовок по словам; появление блоков по скроллу; параллакс размытых пятен; магнитные кнопки; ховер-подъём карточек; счётчик цены; закреплённая секция шагов; прогресс-полоса скролла. Учесть `prefers-reduced-motion`. 60 fps на среднем телефоне, без лагов.

## ПРОДАЖА ПОДПИСОК (этап «боевой»)
- Кнопка «Оформить Pro» → платёжный провайдер (ссылка или виджет) → после оплаты e-mail с ключом. Сервер лицензий уже есть в `RadialMusic/server/` (Flask, providers.py, mailer.py) — переиспользовать, не писать заново.
- Страницы: оферта, политика конфиденциальности (взять черновики из `RadialMusic/legal/`), возврат, контакты.
- Личный кабинет не нужен на первом релизе: ключ приходит на почту, повторная выдача по e-mail.

## ТРЕБОВАНИЯ К КАЧЕСТВУ
Адаптив 320–2560 px; Lighthouse ≥ 90 по всем пунктам; семантичная вёрстка, доступность (фокус, aria, контраст); SEO (title, description, OG, sitemap, JSON-LD SoftwareApplication); изображения webp/avif; шрифты с `display=swap`; любые числа и цены только из `config.js`.
