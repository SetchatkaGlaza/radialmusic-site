# Radial Music — сайт (этапы 1–4 на стороне сайта)

## Запуск
```
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # сборка в dist/
```
Нужен Node.js 18+. `dist/` можно залить на GitHub Pages / Netlify как есть (base './').

## Что где
- `src/config.js` — цены, ссылки, версия, список действий круга (меняй тут).
- `index.html` — секции. `src/styles.css` — дизайн-система (переменные в :root).
- `src/modules/` — smooth (Lenis), reveal (GSAP-анимации), wheel (интерактивный круг), ui (меню, тарифы, шаги, магнитные кнопки).
- `public/assets/studio-logo.png` — логотип студии в подвале.
- `PROMPT-MASTER.md` — мастер-промпт для следующих этапов.

## Этапы 3–4
- `gl.js`: 3D-кольцо three.js за круговым меню (динамический импорт, при ошибке отключается; выключатель `webgl` в config).
- `polish.js`: заставка, кольцо на фоне вращается со скроллом, свечение карточек за курсором, курсор-кольцо.
- `checkout.js`: окно покупки (e-mail, согласие) → сервер лицензий → оплата ЮKassa. Страница `thanks.html`.
- Настройка сервера и ограничения: `docs/SERVER-PATCH-ru.md` (нужен CORS, одна цена, без автопродления).
